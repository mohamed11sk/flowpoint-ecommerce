# 📦 Amazone E-Commerce Store

Welcome to **Amazone**, a complete e-commerce web project with product display, shopping cart, favorites, login, and email order submission.

---

## ✨ Key Features

- 🛒 Product browsing and checkout pages
- ❤️ Favorites page
- 🔐 Login page
- 📝 User profile page
- 📧 Order submission via email using PHPMailer
- 🎨 Clean layout with CSS and JavaScript
- 📁 Organized file structure for easy customization

---

## 🧩 Project Structure

- `index.php` — main product listing page
- `details.php` — product detail page
- `checkout.php` — checkout page
- `favorite.php` — favorites page
- `profile.php` — profile page
- `login.html` — login form
- `send_order_email.php` — handles order email sending

### Folders

- `css/` — styling files
- `js/` — JavaScript scripts
- `includes/` — shared includes and connection files
- `PHPMailer/` — email library
- `image/` — product images and icons

---

## 🚀 How to Run

1. Place the project inside your local server folder, such as `htdocs` in XAMPP.
2. Create a new database and import `ecommerce_store.sql`.
3. Update database settings in `includes/connection.php`.
4. Open your browser and go to:
   - `http://localhost/Amazone/index.php`

---

## 🛠️ Requirements

- PHP
- MySQL
- XAMPP or a similar local development environment
